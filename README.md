# AI Skills Lab 🚀

A landing page for the Laranova × Hexa Media 4-week AI bootcamp in Lefkoşa.

## What I built

I designed this website for an AI bootcamp, applying what I learned in the program. It presents the curriculum (Create, Automate, Monetize), the weekly roadmap, and student results in one clear page.

## Tech Stack

- React + TypeScript + Vite
- Tailwind CSS
- Lucide React icons
- Deployed on Vercel

## Key Features

- **Interactive syllabus tracker:** week-by-week learning roadmap
- **Student case studies:** project grid with results
- **Accordions:** deep dives on multi-agent workflows, RAG, and webhooks
- **Responsive design:** consistent typography and layout on every screen
