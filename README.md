# AI Bootcamp Landing Page 🚀

A professional, high-fidelity landing page for the **Laranova × Hexa Media 4-Week AI Intensive** in Lefkoşa. This entire codebase was rapidly engineered from scratch using advanced **Vibe Coding** workflows, proving the speed and viability of multi-model AI orchestration.

## 📌 Project Overview

This website serves as the primary informational hub and conversion engine for the bootcamp's Winter Edition. It outlines the core curriculum pillars (*Create, Automate, Monetize*), displays chronological weekly tracking data, and showcases historical student proof matrices.

### 🌟 Core Implementations
* **Interactive Syllabus Tracker:** Chronological roadmap charting weekly learning curves.
* **Student Case Studies Matrix:** Visual grid showcasing project applications alongside financial metrics.
* **Deep-Dive Accordions:** Fluid content blocks detailing Multi-Agent loops, RAG, and webhook orchestration.
* **Optimized UI Design System:** Production-grade responsive layouts with cohesive typography systems.

---

## ⚙️ Production Methodology

This production asset was built entirely via conceptual orchestration and rapid AI prototyping:

1. **Verbal Brainstorming & Drafts:** Initial feature scopes mapped out through spoken ideation.
2. **Prompt Refinement:** ChatGPT utilized to optimize prompt definitions and target operational scopes.
3. **Architecture Blueprinting:** Claude engineered the application architectures and master file relationships.
4. **Visual Prototyping:** Lovable generated the interface engine to visually confirm color choices, typography scales, and structural balance.
5. **Codebase Engineering:** Google AI Studio generated the underlying clean functional logic.
6. **Local Persistence:** Quick tracking and adjustments managed locally via text editors before repository pushing.

This workflow allowed a fully realized, content-dense frontend MVP to be shipped in record time, standardizing a highly scalable approach to modern software creation.

## ⚡ Local Setup

### 1. Clone the Platform
```bash
git clone https://github.com
cd ai-bootcamp-website
```

### 2. Dependency Resolution
```bash
npm install
```

### 3. Launch Development Environment
```bash
npm run dev
```
